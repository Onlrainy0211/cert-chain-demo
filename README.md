
# cert-chain-demo
Blockchain certificate storage demo
> Based on C++ simulation of blockchain, for campus certificate deposit.

## Project Introduction
This project simulates a simple blockchain system, which can store campus certificates information.
Every certificate will generate a unique hash value. Once the data is tampered, the hash will change, so we can verify whether the certificate is genuine.

## Features
- Add new certificate records
- Calculate SHA256 hash for each block
- Verify the integrity of certificate data
- Prevent certificate tampering

## How to run
1. Compile cert3.cpp with C++ compiler
2. Run the program in console
3. You can add and view certificate information
